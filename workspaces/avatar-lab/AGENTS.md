# 工作区：小鲸鱼头像工坊

独立于 QQ 聊天主工作区的头像工作区。目标：给桥接账号找一张合适的「DeepSeek 小鲸鱼 / 鲸鱼娘」头像，并保存到本机供桥接使用。

## 输入
- 关键词建议：`DeepSeek 小鲸鱼 蓝色 头发 鲸鱼尾巴 头像 二次元`、`鲸鱼娘 蓝发 Q版`、`蓝色大肥鱼 梗图`。
- 工具：项目根目录的 `scripts/avatar-hunt.mjs`，或直接让桥接 agent 调 `find_avatar`。

## 工作流程
1. 运行：

```bash
node scripts/avatar-hunt.mjs "DeepSeek 小鲸鱼 蓝色 头发 鲸鱼尾巴 头像 二次元" --count 6
```

2. 图片会保存到 `state/avatars/`。用看图工具逐张检查（`read_image`），筛掉：
   - 带明显水印 / 低分辨率 / 拉伸变形；
   - 与「蓝白配色、蓝色长发、鲸鱼尾巴、闭眼或蒙眼」形象差太远的；
   - 真人照片、恐怖/不适内容。
3. 选 1~3 张候选，说明理由（配色、构图、是否有尾巴）。
4. 设置头像：

```bash
node scripts/avatar-hunt.mjs "" --choose 2
```

是否成功取决于 SnowLuma 是否实现 OneBot `set_qq_avatar`；失败时按输出提示在 QQ 客户端手动设置，图片已经保存在本机。

## 注意
- 只下载公网图片；不要用带版权风险的商业素材做公开头像。
- 不要修改 `config.json` 或桥接代码。
- 不要为了「像」而选擦边/引战图；小鲸鱼是群友，不是营业账号。
