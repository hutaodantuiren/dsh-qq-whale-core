# 工作区：QQ 黑话 / 表情包学习（小鲸鱼专属）

这是与 QQ 聊天主工作区分开的「学习工作区」。主桥接只负责收集语料（`state/slang-candidates.json`、`state/slang.json`），这里负责把语料变成可用的群文化知识。

## 目标
- 学习当前群真实在用的黑话、缩写、梗、表情包用法。
- 优先关注 DeepSeek / 小鲸鱼 / 蓝色大肥鱼相关的社区梗，但不要硬玩。
- 产出可直接被桥接读取的词典条目，而不是一篇分析报告。

## 输入
- `../state/slang-candidates.json`：桥接自动统计的高频词（term / count / examples / lastAt）。
- `../state/slang.json`：已收录词典。
- 需要联网确认时，用工作区里的 `web_search` / `web_fetch` 工具（如果当前 DSH 配置提供）。

## 工作流程
1. 读候选文件，挑 `count >= 2`、尚未收录、确实像群内黑话的词。
2. 对每个词：结合 examples 判断语境；不确定就搜索「词 + 梗 + 意思 / 出处」；不要凭想象编含义。
3. 产出 JSON（追加到 `../state/slang.json` 的 `entries`）：

```json
{
  "entries": {
    "难绷": {
      "term": "难绷",
      "meaning": "绷不住了，想笑又无语",
      "usage": "别人说了离谱的话时回一句",
      "tags": ["群常用", "吐槽"],
      "source": "slang-lab",
      "count": 3,
      "createdAt": 0,
      "updatedAt": 0
    }
  }
}
```

4. 表情包：记录 `face` / `mface` 的 id 与常见语境；不要伪造 id。
5. 不确定、低置信、只有一次的词不要收录，留在候选里继续观察。

## 小鲸鱼相关梗的边界
- 「大肥鱼」是雷点，不是自称；词典里可以记录「别人用来逗小鲸鱼，会炸毛」，但对话里不要主动自称。
- 「D指导」「小鲸鱼」「鲸鱼娘」「DeepSeek娘」是常见称呼。
- 「偷吃 token」「服务器繁忙」「事已至此，先吃饭吧」是经典梗，记录用法即可，不要每轮硬玩。

## 禁止
- 不要收录人身攻击、违法、色情、隐私信息。
- 不要把别的群的梗硬搬进当前群。
- 不要修改 `config.json`、不要启动/停止桥接进程；只写学习结果。
